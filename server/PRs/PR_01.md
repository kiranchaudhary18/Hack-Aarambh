# PR Title

Backend: Add fake job offer detector API with PostgreSQL, JWT auth, PDF analysis, and admin analytics

## PR Description

This pull request adds a complete backend service for the Hack-Aarambh fake job offer detector.
The backend is implemented in NestJS with TypeScript and supports authenticated user flows, content analysis, PDF parsing, persistent history storage, and admin analytics.

## What changed

- Added NestJS backend service under `server/`
- Implemented JWT authentication with register/login endpoints
- Added text and PDF analysis endpoints to detect fake job offers
- Added scam scoring logic with red-flag reason extraction
- Persisted history and scan results in PostgreSQL via TypeORM
- Added admin analytics and flagged-case monitoring endpoints
- Added Docker Compose configuration for backend + PostgreSQL
- Added unit tests for analysis score logic
- Added project documentation in `server/PROJECT_OVERVIEW.md`

## Why this change

This backend enables the Hack-Aarambh project to evaluate job offer text and documents for fraudulent indicators, store scan history, and provide analytics for admins.
It provides the foundation needed for frontend integration and future AI/ML enhancements.

## Notes

- Use `server/.env.example` to configure database and JWT settings.
- Run `docker compose up --build` from `server/` to start the backend and PostgreSQL together.
- Run `npm test` from `server/` to execute unit tests.
