# PR Titile

feat: integrate AI-based fake job offer detection system

## 🚀 Overview

This PR introduces the AI-powered Fake Job Offer Detection system into the project.  
The system analyzes job-related text inputs and predicts whether the offer is genuine or potentially fraudulent.

---

## 🧠 Key Features

- Hybrid detection system (Rule-based + ML model)
- Scam probability scoring (0–100)
- Explainable output with detected reasons
- Support for text-based job descriptions
- Modular AI architecture for scalability

---

## ⚙️ AI Implementation Details

- Text preprocessing pipeline (cleaning, normalization)
- TF-IDF vectorization for feature extraction
- Logistic Regression model for classification
- Rule-based detectors for:
  - Suspicious keywords
  - Payment requests
  - Unrealistic salary patterns
  - Unofficial email domains

---

## 📤 Output Format

The system returns:

- Scam score
- Verdict (Likely Scam / Likely Safe)
- Reasons for detection

---

## 🔌 Integration

- Connected AI module with backend API (`/analyze`)
- Seamless integration with frontend UI
